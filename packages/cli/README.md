## Install

```bash
npm install -g @magicdian/transpec
```

## What this package is

`@magicdian/transpec` is the published npm CLI package for the `transpec` project.

- `transpec` is a universal conversion framework for spec-driven projects
- the currently complete workflow is OpenSpec -> Trellis
- normal guided usage happens inside your agent tool through `$transpec-preprocess` and `$transpec-apply`
