## 安装

```bash
npm install -g @magicdian/transpec
```

## 这个包是什么

`@magicdian/transpec` 是 `transpec` 项目的 npm CLI 发布包。

- `transpec` 本身是一个通用的 spec 转换框架
- 当前最完整可用的工作流是 OpenSpec -> Trellis
- 正常使用时，推荐在 agent 工具中执行 `$transpec-preprocess` 和 `$transpec-apply`
